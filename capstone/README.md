# Capstone: Covert Operations Network Security Framework (RFP-CIA-073)

A graduate-level cybersecurity capstone project, structured as a formal proposal response to a fictional government RFP requesting a covert communications security framework for field intelligence operations. Completed by a 4-person capstone team over a full semester.

**[Read the full writeup](./capstone-covert-ops-security-framework.md)**

## What This Covers

The project designs a complete security architecture for a hypothetical high-threat covert communications scenario, including:

- Post-quantum cryptography (NIST FIPS 203/ML-KEM) and hybrid classical/quantum-resistant encryption design
- Hardware-backed, multi-factor authentication using a dual-profile device model and a secure element (Titan M2)
- Phantom, a custom covert communications application with end-to-end encryption, code integrity verification, and a fallback channel
- Traffic obfuscation and anti-detection mechanisms
- Zero Trust architecture and internally managed PKI
- NIST SP 800-61-aligned incident response protocols
- SCAP-based compliance auditing

## My Role

I led design on three core sections: **Advanced Encryption**, **Secure Authentication Protocols**, and the **Phantom** application. I also contributed smaller sections on training materials, audit procedures, and incident response. The remaining sections (Mission Command Center hardware, budget/scheduling, SWOT analysis) were led by teammates and are only summarized for context in the writeup, not detailed.

## Note

This was an academic exercise built around a fictional scenario. It does not reflect real classified systems, real government programs, or actual operational capabilities, and no real classified, proprietary, or sensitive information is included.
